# 资产说明模板

供生成资料时取用；不是要求项目新增“资产说明书”。共同词义为：名称、对应参考、用途、固定外观/空间、当前状态、依据、实际检查状态。只把当前操作需要的字段交付，信息不全注明未核实。

## 人物：与图片同名的 TXT

将下列内容按实际人物填写，去掉示例括号。主体描述用于 TapNow 创建人物；外形复用提示词仅用于重做参考图，两者分开。

```text
人物名称：角色名
参考图片：角色名.png

主体描述：可复制的身份、年龄范围、脸型、发型、体态与固定服装；不夹带机位或三视图排版。

外形复用提示词：沿用对应角色参考，写明所需角度/构图、固定服装与背景；同一人多角度不是多个人。画面无字幕，无额外文字标注。

固定音色：完整音色描述，包含年龄感、语言/口音、音区、音质、吐字与自然程度，不把单句情绪当固定嗓音。

试听台词：一句适合该角色的原文，单独可复制；无发言角色写“无，本片不发言”。

表演说明：基本姿态与表演尺度；单句情绪/语速在视频文档就近交付。

声音状态：仅文字设定，尚未试听或绑定平台声音。已有选用音频/声音 ID 时填写真实来源，不能虚构。
```

如图尚未生成，参考图片写“待生成，计划文件名为角色名.png”，不提供不存在文件的链接。实际看图结论按需要简短附在末尾，不要求复制进平台主体。

## 环境与道具：取用到本镜，不生成逐图说明文件

```text
地点：实际地点。
主要环境锚点：实际选用节点名；普通镜头一个。
连接素材：该锚点 + 必要可见人物/道具；都汇入本镜分镜。
起始状态：上一镜已完成的动作与当下状态。
```

需要时把以下约束融入本镜图片/视频 prompt：

- 外观固定：同一物件的颜色、结构、所属、缺损等；合图不代表多件。
- 空间固定：门窗、桌椅、灯具数量和相对位置；道具已在环境内时校正同一件。
- 状态可变：开合、持物、食物余量、灯光按剧情变化；“外观固定”不等于禁止合法动作。
- 产品依据：照片可见特征、用户已确认功能/安装方式分开；不写未知规格。

例：主要环境锚点为“住处_E02_餐桌正面”，环境里已有一部手机。引用“主人手机”是校正这同一部手机的外观，不新增手机；起始状态为屏幕朝向主人、支架已展开。切到反打仍遵循实际桌面位置。

重做某张图时才提供其当次生成 prompt，不在道具/环境文件夹补 TXT、MD 或逐图 Word。自动字段检查不能替代看图，检查状态须按实际事实填写。
