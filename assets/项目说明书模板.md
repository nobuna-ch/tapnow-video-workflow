# 分类 Word 文档模板

按当前用途取用，分别导出，不将本文件整体做成“项目说明书”。人物主体资料用 [资产说明模板](资产说明模板.md)；这里不收纳人物总册。

## 文件和排版

正式名称：剧本.docx、分镜图提示词.docx、视频提示词与台词.docx。相同名 Markdown 在归档/文档源稿。无版号尾缀、版本记录、单独封面或默认目录导航。只创建当前阶段需要的文档；一镜用真实二级标题，提示词和台词是可复制普通正文。

标题为“项目名称 文档类型”；紧接必要使用说明后进入正文。时间统一用“全片 A—B 秒｜成片时长 N 秒”，N 等于 B−A。镜内从本镜0秒计，跨镜音频只生成一次。

下方尖括号表示需填写的内容，不能原样交付。完整可执行示例见 [最小示例](../examples/最小示例/归档/文档源稿/剧本.md)。

## 剧本

只写剧情与必要制作备注，不包含逐镜 prompt。示例结构：

```text
# <项目名> 剧本
目标时长：<秒数>。画幅：<比例>。视觉风格：<风格>。
一句话故事：<表达目标/故事>。
人物关系：<需要的人物关系；无人物则注明>。

## 场次01 <时段·地点>
预计时长：<秒数>，包含动作、对白和停顿。
动作：<可见行为及先后关系>。
<角色>：<台词原文>。
<无对白场次明确写“对白：无”>。
```

## 分镜图提示词

```text
# <项目名> 分镜图提示词
<只有必要的一两句用法。缺图阶段注明计划节点待生成，不伪造链接。>

## 镜头01 <简短动作名>
全片 0—4 秒｜成片时长 4 秒
地点：<地点>。
主要环境锚点：<唯一主要锚点；特例写类型与来源>。
连接素材：<主要锚点 + 必要可见人物/道具> → 分镜_01。
起始状态：<本镜第一帧的确定瞬间，继承此前状态>。

### 分镜图 prompt
<地点 + 锚点 + 景别 + 人物位置/瞬间动作 + 必要道具 + 构图 + 光线 + 情绪。画面无字幕，无额外文字标注。>

衔接：<前镜接点；本镜结束状态如何进入下一镜>。
```

分镜图仅画一个瞬间。素材存在时链接实际文件，已有环境内的道具只校正同一实例。纯空镜、复用末帧、现成尾片写清来源；不为了字段硬连房间锚点。普通单画面不同时连接多个近似环境图。分屏每侧一个锚点，各自生成后合成。

## 视频提示词与台词

```text
# <项目名> 视频提示词与台词
<说明实际生成在 TapNow；时长为剪辑目标，最终按选用视频/音频校准。>

## 镜头01 <与分镜一致>
全片 0—4 秒｜成片时长 4 秒
画面输入：仅已选分镜_01 → 视频_01。
起始状态：<与分镜一致>。

### 视频 prompt 与对应台词
以@分镜_01为首帧。<主体动作、运镜、时间节奏、表情、环境动态、禁止变化项。可见角色在镜内指定时段说：“实际台词”。画面无字幕，无额外文字标注。>

动作记录：<起始 → 动作 → 结束>。

**<角色名>台词**
<单独一段纯台词，不带角色或朗读备注。>
固定音色：<完整固定音色，不写同上>。
情绪与语速：<该句情绪>；语速：<建议字/秒或清楚的自然快慢>。
发言时机：镜内 <A—B> 秒，对应全片 <A—B> 秒；按实际成音校准。

音效：<无；或复用来源/覆盖时段；或下述完整独立音效>。
衔接：<动作/视线/声音/空间接点和下一镜起始状态>。
```

无台词写“台词：无”。画外声音注明画外，镜内人只听。可见人物说话时视频 prompt 包含真实原句，允许原生对白辅助口型；独立配音合成时选一份声音，实际支持时使用音频驱动/口型处理，不承诺换音轨自动精准同步。整段音色不是音频 ID，未试听不得写已锁定声音。

跨镜对白只交付一次完整音频，写明源镜、全片窗口及跨入下一镜的尾段，接收镜注明复用。台词变动同步剧本、视频内实际原句、独立原文和时长。

独立音效格式（在所属镜头紧邻交付，不另做总册）：

```text
音效：<中文名称>。
音效 prompt：<声源、动作、空间远近、必要变化。无人声，无音乐。>
建议素材时长：<秒数>。
出现时机：<镜内/全片时间或可观察动作，按视频对齐>。
```

连续底噪复用选用节点，注明覆盖哪些镜；不每镜重复生成。现成品牌尾片保留原声音时写清，不凭空增加音效。

## 可选文件

只有用户需要集中进度时才做一页左右的项目说明书；只放当前阶段、约定、真实文件入口、下一步，不复制上述正文。素材与节点连接文档仅在用户提出整理需求时维护，名字清晰、连线按实际依赖，不另加操作手册。
