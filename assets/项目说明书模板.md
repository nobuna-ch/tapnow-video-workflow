# 分类 Word 文档模板

按阶段取用，分别导出，不把本文件整体导成“项目说明书”。本模板保留旧文件名只为兼容既有调用；资产使用 [资产说明模板](资产说明模板.md)。

## 文件和排版

新项目默认四类当前稿：`剧本.docx`、`资产设定.docx`、`分镜.docx`、`视频提示词.docx`，同名 Markdown 放在 `归档/文档源稿/`。只创建实际完成阶段的文档。旧名“分镜图提示词”“视频提示词与台词”继续兼容读取，不批量迁移历史，不为同一内容同时交付新旧两套。

标题为“项目名称 文档类型”，紧接必要说明和正文，无版号、版本记录、独立封面或默认目录。一镜使用真实二级标题 `## 镜头01 动作名`；分镜时间为“全片 A—B 秒｜成片时长 N 秒”，N 等于 B−A。

尖括号内容须填写，不能原样交付。评审报告、尝试次数、审批和流程状态留在临时工作，不写进 owner Word。完整文字示例见 [最小示例](../examples/最小示例/归档/文档源稿/剧本.md)。

## 剧本

只写剧情与必要制作备注，不含逐镜 prompt。

```text
# <项目名> 剧本
目标时长：<秒数>。画幅：<比例>。视觉风格：<风格>。
一句话故事：<故事或表达目标>。
人物关系：<必要关系；无人物则注明>。

## 场次01 <时段·地点>
预计时长：<秒数，包含动作、对白和停顿>。
动作：<可见行为及先后关系>。
<角色>：<台词原文>。
<无对白场次写“对白：无”>。
制作备注：<只保留影响连续性、品牌表达或执行的约束>。
```

## 资产设定

按 [资产说明模板](资产说明模板.md) 把人物、产品/道具、环境和必要音色集中放入同一 Word。人物如“父亲”，道具如“父亲手机”，环境如“客厅正面”“客厅窗侧”；三视图是图像内容，不是实体名，不默认逐图创建 TXT。

素材已存在则链接实际文件；未生成写“待生成，计划文件名为……”，不放假链接。只保留使用资产需要的设定和依据，视觉评审及调用记录留在内部状态。

## 分镜

每镜只画一个明确瞬间。普通单画面只选一个主要环境锚点，必要可见人物和道具并行输入。画外说话人不因此入画。

以下四反引号用于展示模板，实际源稿使用其中的三反引号 text 块：

````markdown
# <项目名> 分镜
<必要说明；无图阶段注明计划节点待生成。>

## 镜头01 <简短动作名>
全片 0—5 秒｜成片时长 5 秒
地点：<地点>。
主要环境锚点：<唯一主要锚点；特例注明类型与来源>。
连接素材：<主要锚点 + 必要可见人物/道具> → 分镜01。
起始状态：<第一帧的确定瞬间，继承此前已完成状态>。

### 分镜图 prompt
```text
<地点、锚点、景别、人物位置与瞬间动作、必要道具、构图关系、光线与情绪。按实际绑定资料使用 @名称。画面无字幕，无额外文字标注。>
```

衔接：<前镜接点，以及本镜结束后进入下一镜的状态>。
````

环境已有物件只校正同一实例。独立空镜、复用末帧和现成尾片写清来源，不强连室内锚点；分屏每侧一个锚点，各自生成后合成。节点名称中的下划线等字符在 Markdown 用行内代码或 text 块保护，Word 中仍为可复制原文。

## 视频提示词

每节点只交付三行外部设置和一块完整提示词。模式按实际入口选择“首帧 / 首尾帧 / 全能参考 / 文本”，建议时长是生成/剪辑目标，不表示平台已有此参数。正文外不另列动作记录、独立台词、音色表、发言窗口或独立音效 prompt。

````markdown
# <项目名> 视频提示词
<必要说明；输入素材在软件中选择，建议时长按选用结果校准。>

## 镜头01 <与分镜一致>
模式：首帧
输入素材：首帧=分镜01
建议时长：5秒

```text
<主体动作、镜头、节奏、表情变化、环境动态和禁止变化项；从起始状态演变到结束状态。需要发言先后时直接写在本段。>
音效：<随本镜生成的环境声/动作声及同步关系；无则写“无”>。
对白：<角色>：<原句>。<必要的完整音色、情绪、语速或画外说明也写在本块；无对白写“对白：无”。>
```
````

四种输入写法：

- 首帧：`输入素材：首帧=分镜01`。在软件首帧位置选图，正文不机械添加“以 @分镜01 为首帧”。
- 首尾帧：`输入素材：首帧=分镜01；尾帧=分镜02`。两端在软件指定，正文描述两端之间可实现的运动，不把尾帧当第二件场景或物件。
- 全能参考：`输入素材：父亲、父亲手机、客厅正面`。只列实际选用资料；正文按绑定名称使用 `@父亲` 等，说明各自控制身份、物件外观或空间的用途。
- 文本：`输入素材：无`。不用未绑定的 @ 引用，以充分文字描述画面。

参考模式的 @素材名 后接空格或标点，例如“@父亲 保持身份外观”，避免名称与动作粘连。

一个 text 块即一次完整复制。音效、对白和必要音色随视频生成，无需求分别明写“无”。不单独交付 TTS/audio/SFX prompt，不让 owner 跨块拼接，不安排默认独立配音、试听样音或后期换轨。

可见人物写真实台词，动作段注明说话在动作前/中/后；画外声在对白行标画外，画内人倾听。完整音色不写“同上”，本句情绪与语速按需给出；文字音色不等于平台声音已绑定，口型和声音以实际结果判断。

跨镜长句优先调整切点，或在实际入口支持时合并为一个可执行节点使整句完成，不默认拆成多条独立音频。复用末帧和现成尾片在分镜写来源及剪辑处理，视频文档只写需要生成的节点。

## 可选文件

仅当 owner 明确需要集中进度时，才做约一页的 `项目说明书.docx`，放阶段、约定、文件入口和下一步，不复制正文。节点连接清单也仅按用户明确需要维护。
