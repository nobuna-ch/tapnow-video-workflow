# 明天接着看 分镜

文字示例：以下均为待生成计划素材，画面未验证。先选用人物、道具与阅读角参考，再生成干净分镜；近景沿用同一锚点。

## 镜头01 合上书

全片 0—5 秒｜成片时长 5 秒

地点：阅读角。

主要环境锚点：阅读角正面（待生成节点）。

连接素材：阅读角正面、小林、灰色硬壳书 → 分镜01。参考图均待生成，桌面已有的书是同一件，不再增加一本。

起始状态：小林已坐定，书已打开，右手轻放在右侧封面外缘，准备说话。

### 分镜图 prompt

```text
@阅读角正面，傍晚阅读角固定中景。@小林 坐在桌后，低头看打开的 @灰色硬壳书，右手轻放在右侧封面外缘，神情放松。保持桌椅和窗位的空间关系、窗侧柔和自然光及米白色长袖，桌面只有这一本书。画面无字幕，无额外文字标注，不出现可读书名。
```

衔接：以已坐定状态开场；本镜视频结束时书已合上、右手仍在封面，下一镜从同一状态开始。

## 镜头02 手离开封面

全片 5—8 秒｜成片时长 3 秒

地点：阅读角，同侧桌面。

主要环境锚点：阅读角正面（沿用同一机位同侧裁近，不新增房间参考）。

连接素材：阅读角正面、小林、灰色硬壳书 → 分镜02。人物参考只用于手和袖口一致，不让脸入画。

起始状态：书已闭合，小林右手仍轻放封面，书和手的方向继承镜01结束。

### 分镜图 prompt

```text
@阅读角正面，同侧裁近为桌面近景。已闭合的 @灰色硬壳书 放在原位置，@小林 的右手轻放在封面上，只见手和米白色袖口，脸不入画。保持同一桌面纹理、书的朝向和窗侧自然光，不增添物件。画面无字幕，无额外文字标注，不出现可读书名。
```

衔接：承接镜01已闭合的书与右手位置，约1秒完成手退出，随后保持无人手桌面两秒结束；不重复合书，也不重新打开。
