# 明天接着看 视频提示词与台词

文字示例，分镜和声音尚未生成或选用。视频只接同镜选用图；台词音频独立生成，但与视频同镜配套。时间是成片目标，实际口型和发言窗口按平台能力及选用结果校准。

## 镜头01 合上书

全片 0—4 秒｜成片时长 4 秒

画面输入：仅已选`分镜_01` → `视频_01`，不再连环境、人物与道具原图。

起始状态：小林已坐定，书打开，右手轻放在右侧封面外缘。

### 视频 prompt 与对应台词

```text
以@分镜_01为首帧，摄影机固定。小林低头看书，在镜内0.3至2秒轻声说：“明天接着看。”说完于2至3.8秒用右手缓慢合上书，末尾右手停在闭合封面上。书、桌面、服装和窗位不改变，不增添物件，自然光保持稳定，表情轻松。画面无字幕，无额外文字标注。
```

动作记录：书打开、右手在封面边 → 说话并合书 → 书已闭合、右手停在封面。

**小林台词**

明天接着看。

固定音色：约30岁中国女性，自然普通话，中音区，音质清亮柔和，吐字清楚但不刻意，呼吸像日常聊天，无播音腔。当前仅文字音色设定，尚未试听或绑定声音。

情绪与语速：轻松、有一点舍不得；语速：约3字/秒，句尾自然落下。

发言时机：镜内0.3—2秒，对应全片0.3—2秒；按实际成音微调。视频内原生对白与独立声音合成时选用一份，实际支持时用音频驱动或口型处理，不保证只换音轨就精确同步。

音效：合书轻响。

音效 prompt：安静阅读角内，一本硬壳书被缓慢合拢，纸页轻擦后发出一次柔和的封面合拢声，近距离，自然轻微。无人声，无音乐。

建议素材时长：2秒。

出现时机：镜内2—3.8秒，对应全片2—3.8秒；纸页声跟随合书，封面响对齐实际合拢瞬间。视频原生同类声不重复叠加。

衔接：镜末书已闭合，右手留在封面，切镜02同侧近景保留这个状态。

## 镜头02 手离开封面

全片 4—6 秒｜成片时长 2 秒

画面输入：仅已选`分镜_02` → `视频_02`。

起始状态：灰色硬壳书已闭合，小林右手在封面，方向承接镜01。

### 视频 prompt 与对应台词

```text
以@分镜_02为首帧，摄影机固定。镜内0至1.5秒，小林右手缓慢离开封面并退出画面，末尾保持无人手的桌面近景。书始终闭合且不移动，不再重复合书，服装袖口、桌面纹理和光线不变。画面无字幕，无额外文字标注。
```

动作记录：右手在已闭合书上 → 右手缓慢退出 → 书保持闭合、画面无人手。

台词：无。

音效：无新增独立音效，不重复镜01合书声。

衔接：以手完全离开的稳定末帧供镜03复用；不回到打开的书。

## 镜头03 留住这一刻

全片 6—8 秒｜成片时长 2 秒

画面输入：直接复用`视频_02`选用末帧，无需新视频生成。

起始状态：书已闭合，画面无人手。

### 视频 prompt 与对应台词

无需生成。将镜02选用视频末帧延续两秒，保持同一书、桌面、光线，画面无字幕，无额外文字标注。

动作记录：无人手桌面末帧 → 保持两秒 → 结束。

台词：无。

音效：无。

衔接：保持同一构图结束，不增加物件或改回旧状态。
