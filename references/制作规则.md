# 制作规则：重复物件、产品依据与关联修改

用于资产准备、资产变更和分镜连续性审查。这是检查方法，不要求每项目新增台账；结论写进现有文档，只有人物主体资料默认独立 TXT。

## 逐段审查

沿剧本段落顺序核对，再跨相邻镜头检查：

1. **谁在画面里**：人物、画外说话人分开，手机内人物与现场人物分开。
2. **物件在哪里、属于谁**：反复出现、被操作、承载剧情/品牌或易被模型误改的物件需要固定。背景杂物由环境图控制，不逐件建资产。
3. **同一物件还是不同物件**：两地手机保留所属前缀；颜色、镜头模组、裂痕、支架等区别不能切镜后互换。多视图中的多个角度表示同一件物品。
4. **环境是否已有该物件**：再次引用道具是校正现有实例，不能叠加第二盏灯、第二部手机、第二套餐具。
5. **状态如何变化**：只记录影响下一镜的状态，例如“盒盖关闭 → 开盒一次 → 独立盒盖在人物右手侧”，或“整块 → 分开 → 少一口”。造型参考不能覆盖已完成动作。
6. **反打是否真实**：左右以人物/房间实际位置为依据，不要求反打中物件永远在屏幕同侧。窗、桌、门、灯数量与相对位置不能随机变化。

主要角色、关键产品、反复操作的专属物件优先独立资产；窗户通常属于环境锚点，特定近景需要时才独立；月亮等两地共享视觉可复用同一参考，不强塞进室内图。

例如：餐盒、水杯、筷子已在桌面锚点中，分镜只需校正餐盒外观与筷子当前位置，不需再生成一套“桌面道具主体”。两地同款杯也不能未经依据写成同一实体。

## 产品实物依据

| 信息 | 可用依据 | 处理方式 |
| --- | --- | --- |
| 可见外形、分层、纹理、颜色关系 | 用户实物照片、已选资产 | 多角度互证；遮挡部分未核实，不补造 |
| 安装方式、型号、尺寸、功能 | 用户明确说明、产品规格资料 | 使用已提供事实；保留简短来源，不重复确认 |
| 品牌标识、标语 | 用户原始品牌素材 | 保留原内容，不造新标志 |
| 材质成分、照度、显色、响应参数 | 对应规格/测试依据 | 仅凭外观不作断言；未给出不写广告承诺 |

展厅支架、标签、电线、展示台不自动属于家中安装状态。区分产品结构与展示附属物，不能把吸顶灯画成桌灯。可写“呈石纹外观”，不能凭纹理认定天然石材。

产品动作有因果：用户确认支持语音调暗后，可安排口令、灯光响应、人物赏月，后镜继承低亮状态。不能用整个画面变暗冒充灯具自身变化；画面用时不是设备响应参数。

## 修改后的关联核查

| 变更 | 要核查的当前内容 |
| --- | --- |
| 人物外貌/服装 | 人物图与 TXT、出现该人物的分镜、视频外观约束 |
| 人物声音 | 人物 TXT、每句音色与声音状态、跨镜复用；外貌没变不重生图 |
| 道具外形/所属/数量 | 环境内占位物、分镜引用、视频操作与结束状态、已有连接清单 |
| 环境构图/机位名称 | 选用锚点、主要锚点字段、prompt 的 @ 名、连接、同轴裁景 |
| 产品功能/亮度 | 剧本动机、操作/响应/反应镜、后镜状态、声音与总时长 |
| 台词或插镜 | 剧本对白、分镜瞬间、视频实际台词、纯台词与窗口、跨镜音频与总时长 |

更新后查旧名称、失效链接、镜号/时间不一致及遗漏的旧状态。只改受影响文档，不扩充无关资产。脚本能找部分缺失和冲突，语义依赖须实际读稿；不能称已自动覆盖全部关联。

历史稿与原始来稿保持冻结。TapNow 节点或已选视频不会因本地更名自动更新；指出受影响节点/镜头，由 owner 在平台替换。

## 模板使用与视觉检查

按 [资产说明模板](../assets/资产说明模板.md) 统一字段词义，不统一成额外文件：人物使用图旁 TXT；环境/道具只把本镜必要的名称、用途/依据、固定项和状态放入分镜；重做图时才提供该次生成 prompt。未生成图写计划节点，不放指向不存在文件的链接。

实际查看各角度/格子中的身份服装、物件个数、结构、裂痕、持物手、接触遮挡、透视和空间，产品与实物对照。文件存在、TXT 完整、图片尺寸正常不是视觉通过证据。看不到的细节不打勾。

局部问题只修局部；同类失败重复时简化动作或构图，停止盲目重试。计划图是“待生成”；生成未看为“待查看”；问题图为“需修正”；实际确认后才是“已确认”。
