# 制作规则：视觉依据、连续性与关联修改

人物、产品/道具、环境集中进入 `资产设定.docx`；本镜执行信息进入分镜与视频提示词。内部评审、冻结项、额度和尝试记录集中于 `临时工作/流程状态.json`，不新增逐图台账或说明文件。

## 从剧本到资产

先确认剧本已通过适用的 owner gate，保留已批准事实、人物关系、结尾与表达。按剧情需要确定必需资产和视角：主要角色、关键产品、反复操作的专属物件优先独立；窗户通常属于环境，特定近景需要时才独立；同一月亮可作两地共享视觉，不强塞入室内锚点。

沿剧本顺序审查，再跨相关镜头检查：

1. 谁在画面里：分清现场人物、画外说话人和手机内人物；画外发言者不因此入画。
2. 物件在哪里、属于谁：固定反复出现、被操作、承载剧情/品牌或易被误改的物件，背景杂物由环境控制。
3. 同一物件还是不同物件：两地手机保留所属，颜色、镜头模组、裂痕和支架不能切镜互换；多视图表示同一实体，不表示多件。
4. 环境是否已有物件：道具引用校正已有实例，不能叠加第二盏灯、第二部手机或第二套餐具。
5. 状态如何变化：追踪影响后镜的状态，如“盒盖关闭 → 开盒一次 → 盒盖在人物右手侧”“完整 → 分开 → 少一口”。造型参考不能恢复已吃食物，后镜不能重复已完成动作。
6. 空间和反打是否真实：左右以人物和房间实际位置为依据，不要求反打后物件仍在屏幕同侧；门窗、桌、灯数量与相对位置不能漂移。

餐盒、水杯和筷子已在桌面锚点中时，只校正餐盒外观与筷子当前位置，不再生成一套桌面道具。不同地点的同款杯也不能无依据写成同一实体。

## 命名、锚点与参考

新人物如“父亲”，道具如“父亲手机”，环境如“客厅正面”“客厅窗侧”。“三视图”只描述图片内容。已有项目沿用有效名称，避免无意义更名。

环境按真实图像整理为镜头锚点，不能靠九宫格格位猜方向。相似图为备用，普通镜头只选一个主要环境锚点；缺少可信反打时优先同侧裁近。人物和必要道具与锚点并行输入，不把人物 → 道具串成生成链；九宫格不能直接作干净首帧。

分镜 prompt 描述一个瞬间：地点、主要锚点、景别、人物位置/瞬间动作、必要道具、构图、光线与情绪。视频描述之后的动作、镜头、节奏和结束状态，不再堆叠全部原始素材。

默认无字幕、无额外文字标注；剧情需要的招牌、书本或真实产品标识按要求保留，不能误删合法品牌标识。用户要求的片尾文案、字幕或现成品牌尾片照常执行。

## 独立视觉审查

图像生成或修改后，交由未参与本次生成的评审者实际查看文件。评审者应收到当前候选图、原始实物/人物身份参考、已批准资产设定、已批准风格图，以及当前镜意图和相关前后镜已锁定状态/选用图。没有真实风格锚点时只依据已批准文字要求，说明证据边界，不能伪称已对图。

逐张、逐视角核对身份、服装、人体/接触关系、产品结构/颜色/标识、物件个数、透视、空间、光线、构图和情绪。审美同时对照风格锚点与叙事目的，不只追随上一张生成结果。看不到的细节不能判通过；文件存在、尺寸正确、prompt 通过都不是视觉通过证据。

每位评审最多三条实质问题，给位置、可见证据、影响与最小修复。身份、数量、品牌事实、必需动作与连续性是硬约束，偏好不能自动升级为阻塞。不下载 GPU 审美模型，不增加模型服务，不用虚构分数代替实际看图。

## 有界生成与冻结

先锁定本批必需资产/视角集合，数量为 N。每项初次生成后至多两次修复，整批共享额外生成池为 ceil(N/2)，先到的上限生效。实际调用、候选和尝试都记入内部状态，不能以换代理、换 Goal 或改名重置额度；一次调用多图也须如实记录。

初图先审后修，身份/数量/产品错误优先，局部问题只修局部。已通过资产冻结，仅对新事实或新要求影响的项重新开放。同类问题重复、修复无进展或达到额度就停止，保留最佳候选和具体未通过原因，不冒充成功，不要求 owner 默认逐图审批。

全部必需资产视觉通过后进入分镜。缺图像能力时可交付资产文字设定及待执行提示词，但图像资产仍未完成，不能视为真实资产验收。

分镜支持出图与 prompt-only 分支。出图遵守独立实际看图及额度；prompt-only 检查引用、动作、空间和连续性，完成即交付“提示词通过，画面未验证”，无需等待平台回传，不冒称视觉通过。

## 产品实物依据

| 信息 | 可用依据 | 处理方式 |
| --- | --- | --- |
| 可见外形、分层、纹理、颜色 | 实物照片、已选资产 | 多角度互证，遮挡部分未核实，不补造 |
| 安装方式、型号、尺寸、功能 | 用户明确说明、可靠规格 | 使用已提供事实，保留必要来源，不重复确认 |
| 品牌标识、标语 | 用户原始品牌素材 | 保留原内容，不造新标志 |
| 材质成分、照度、显色、响应参数 | 规格或测试依据 | 不凭外观断言，不写无依据广告承诺 |

展厅支架、标签、电线和展示台不自动属于家中安装状态。区分产品与展示附属物，不能把吸顶灯画成桌灯；可写“呈石纹外观”，不能凭纹理断言天然石材。

按“操作 → 响应 → 人物反应”展示已确认功能。确认支持语音调暗后可安排口令、灯具亮度响应与人物赏月，后镜继承低亮状态。不能让整个画面变暗冒充灯具自身变化，剪辑用时不是设备响应参数。

## 视频、声音与衔接

每节点只交付外部“模式、输入素材、建议时长”与一个完整 text 块。块内先写动作/镜头，末尾接“音效：”和“对白：”；必要音色、情绪、语速与发言先后同块，无则明写无。不另拆独立 audio/TTS/SFX prompt、动作记录、纯台词或外部发言窗口。

首帧和首尾帧在软件相应位置选图，正文不机械写“以 @分镜为首帧”。全能参考模式按实际资料用 @名称并说明身份、产品或空间用途；文本模式不用虚构引用。视频默认只继承同镜已选分镜，额外参考须有实际用途；引用名与输入一致。

可见说话人用真实原句并配合口型；画外对白标画外，画内人倾听。声音随视频生成，完整音色不写“同上”。台词变更同步剧本、受影响视频块和估时，不默认另做音效素材、独立配音或后期换轨；未听到结果不能声称声音验收。

逐对核对前镜结束和后镜起始的动作、视线、空间与声音接点，也核对非相邻镜头累计状态。产品特写、月亮等空镜需有出现动机和回人物接点。跨镜长句优先调整切点，或在实际入口适合时合并为一个节点使整句说完，不默认拆成多条声音。

分屏每侧用自己的一个锚点或选用末帧，分别生成后合成；注明左右来源、同步时长、裁切和声音归属，不把多个房间塞进同一生成节点，不镜像空间强造对称。后续虚化继承合成画面。

多镜合并只在实际入口适合时建议，给出所含镜号、动作/切镜顺序、各段与总时长、参考和一块完整 prompt；总时长够短不等于适合合并。末帧复用和现成尾片在分镜写来源与剪辑处理，不硬造生成节点。

## 修改后的关联核查

| 变更 | 检查受影响的当前内容 |
| --- | --- |
| 人物外貌/服装 | 资产设定、人物图、相关分镜及视频外观约束 |
| 人物音色 | 资产设定、相关视频复制块；外貌未变不重生图 |
| 道具外形/所属/数量 | 环境占位物、分镜引用、视频操作与结束状态 |
| 环境构图/机位名称 | 锚点字段、prompt 引用、输入素材、同轴裁景 |
| 产品功能/亮度 | 剧本动机、操作/响应/反应镜、后镜状态与估时 |
| 台词或插镜 | 剧本原句、分镜瞬间、视频对白、接点与总时长 |

局部措辞只复审相关维度；改变锁定事实、伏笔、人物关系或结尾才沿语义依赖检查下游。查旧名、失效链接、镜号/时长冲突和遗漏旧状态，只修受影响内容，不顺手重写全片。脚本只覆盖部分静态冲突，不能宣称覆盖全部语义依赖。

历史稿与原始来稿冻结。TapNow 节点和已选结果不会因本地改名自动更新；需重新选用时说明影响范围，不声称已同步平台。
