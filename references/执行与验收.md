# 执行与验收

自动检查适用于模板化当前稿，不能代替独立读稿、实际看图和页面检查。不虚填字段，不把内部通过写成 owner 已批准。

## 阶段边界与内部状态

全项目只维护一个 `临时工作/流程状态.json`，记录阶段、锁定项、候选与对应评审、最佳候选、问题与修复、owner gate、额度、真实调用及检查范围。评审绑定实际看到的候选；改稿后不能复用旧稿通过结论。状态、评审报告、次数和审批记录不进入 owner 的四类 Word。

剧本默认一位主笔、三位独立评审，分别检查结构与观众、人物与对白、品牌与可制作性。每位最多三条实质问题，给位置、证据、影响与最小修复。初稿加至多两次实质返修，通过即停止；同一问题重复或来回改动时停止自动循环，保留最佳候选与阻塞原因。硬约束不能被主观评分抵消。

内部通过剧本后到 owner gate，只有明确批准或已有适用批准才进入资产。到 gate 即交付当前阶段，不空转等待，不擅自把 Goal 设为 paused；未通过或额度耗尽时如实交付问题和下一步。

资产与分镜出图均需独立实际看图。每项初次生成后至多两次修复，整批共享额外生成池 ceil(N/2)，先到上限即止，额度不随代理/Goal 重启。真实调用必须记录；可取得宿主 token 用量则用真实值，不能取得则写未知，不用估算冒充硬预算。预留最终复审、文档检查与交付能力。

分镜 prompt-only 分支完成后可交付“提示词通过，画面未验证”，无需平台回传，不能据此记视觉通过。缺图、未看图、未听声音都保留证据边界。详细视觉依据、冻结与修改见 [制作规则](制作规则.md)。

## 制作正文必需信息

| 文档 | 必需信息 | 合理例外 |
| --- | --- | --- |
| 剧本 | 目标时长、画幅、风格、故事/表达目标、必要人物关系、分场动作、对白或无、预计时长 | 无人物/对白片如实注明 |
| 资产设定 | 人物/道具或产品/环境小节、参考图片、主体描述或设定；人物必要固定音色 | 图片未生成写待生成及计划名；不发言写音色为无；依据/用途/剧情状态变化按需写 |
| 分镜 | 镜号、全片起止与成片时长、地点、主要环境锚点、连接素材、起始状态、图片 prompt、衔接 | 空镜、末帧复用、现成尾片注明类型/来源；分屏每侧一锚点后合成 |
| 视频提示词 | 镜号；块外的模式、输入素材、建议时长；唯一 text 块内动作/镜头、音效、对白 | 无对白/音效写无；无需生成的复用镜在分镜说明 |

标准标题为 `## 镜头01`。视频模式按实际输入为“首帧 / 首尾帧 / 全能参考 / 文本”。输入分别形如 `首帧=分镜01`、`首帧=分镜01；尾帧=分镜02`、实际资料名清单、`无`。`建议时长：5秒` 是节点目标，不保证平台支持任意时长。

每节点恰有一个完整 text 块，末尾含 `音效：...` 及 `对白：角色：原句` 或 `对白：无`，必要音色/表演同块。首尾帧通过软件选图，正文不要求 @首尾帧；参考模式只按实际输入 @引用并说明用途。不拆独立声音 prompt、纯台词块、外部发言窗口或动作记录。

分镜镜号与需生成的视频节点对应，时间连续且可核算；复用镜/合并节点有明确来源/范围。台词与剧本一致，画外声不能让其他角色代说。实际读句意和状态，不能只找字段。

## 路径、兼容与更新

```text
项目/
  剧本.docx
  资产设定.docx
  分镜.docx
  视频提示词.docx
  制作素材/人物、环境、道具/
  归档/
    文档源稿/同名.md
    历史版本/            # 仅既有冻结稿
    原始资料/原稿/      # 原名原内容
    临时工作/           # 已结束工作
  临时工作/
    流程状态.json       # 内部流程事实
    导出预览/           # 候选DOCX和页面检查
```

按需建目录，按阶段创建文档。新稿默认四新名；旧名“分镜图提示词”“视频提示词与台词”兼容读取，不批量迁移历史，不保留双份当前入口。既有人物 TXT 可读取，不再默认新增逐图说明。

正式 Markdown 放 `归档/文档源稿/`，DOCX 在根目录。工作路径使用项目 `临时工作/` 或 `归档/临时工作/`；非标准/嵌套源稿显式传 `--项目目录`，不从多层临时路径猜根。解析后检查项目边界，不能只比较字符串前缀。

更新前读取现有 Word 正文、批注/修订并合并用户修改；`--更新` 不替代合并。正文未变不重导出。导出器检查候选结构、链接和配对后原子替换；错误/占用时保留原件，不强关文档，不另造编号文件。

先草稿导出、渲染并逐页查看，再更新正式稿。多份 Word/MD 不是文件系统事务，覆盖前在项目临时工作留必要回滚内容；中途失败恢复或明确待完成，不称全部同步。历史/原始资料冻结，历史链接只指向冻结内容，不自动生成历史副本、日期或“最终版”尾缀。

## 调用

流程守卫脚本为 `scripts/流程守卫.py`，其状态约定和 CLI 见 [自动评审](自动评审.md)，此处不重复维护。

`<技能目录>`、`<项目目录>` 替换为真实绝对路径，使用已有 Python 并加 `-B`。文档运行库先查询宿主 `load_workspace_dependencies`，不重复安装已有依赖。

```text
python -B -X utf8 "<技能目录>/scripts/环境自检.py" --要求 text
python -B -X utf8 "<技能目录>/scripts/检查项目.py" "<项目目录>" --模式 text
python -B -X utf8 "<技能目录>/scripts/导出说明书.py" "<项目目录>/归档/文档源稿/分镜.md" --项目目录 "<项目目录>" --草稿
```

其他三类逐份同样导出。草稿默认到 `临时工作/导出预览/同名.docx`；`--输出` 只可指定上述两类项目工作目录的同名文件。看图后正式导出：

```text
python -B -X utf8 "<技能目录>/scripts/导出说明书.py" "<项目目录>/归档/文档源稿/分镜.md" --项目目录 "<项目目录>" --更新
python -B -X utf8 "<技能目录>/scripts/检查项目.py" "<项目目录>" --模式 word
```

首次无同名目标可省 `--更新`。自定义导出/库调用也跑最终检查。明确授权修复历史才用 `--修复归档`，只在原历史位置处理，不复制成当前入口。

未知用途只允许草稿导出，不新增正式入口。默认无目录；owner 明确需要时才用 `--目录` 并验证跳转。模板支持标题、段落、列表、链接、本地图片、text 块和分页，不把复杂表格或 HTML 当已支持。

## 检查层与证据边界

| 检查层 | 能证明 | 不能证明 |
| --- | --- | --- |
| 环境自检 | Python/库及部分工具可用 | 云端权限、TapNow 功能、实际渲染成功 |
| 流程守卫 | 已记录阶段、候选评审绑定、gate、次数/额度及停止条件 | 审美质量、评审者真的理解内容 |
| 文字检查 | 命名/字段、部分镜号/时长、引用与静态依赖 | 台词自然、动作可行、物件数量或产品功能 |
| Word 配对 | 文档包可打开，正文/图片/链接与源稿配对 | 图片内容正确、无溢出或分页舒适 |
| 独立读稿/看图 | 实际内容的连续性、身份、实物与风格一致性 | 未提供视频、未听声音、遮挡细节 |
| 页面渲染 | 已逐页查看 DOCX 的排版 | 所有办公软件均相同 |
| 实际视频选用 | 已查看/听到结果的口型、动作、声音与切镜 | 不能由文件存在或 prompt 通过代替 |

仅在覆盖范围内说“通过”。不可用模块、未知状态、异常、未验证项如实说明，不能吞掉错误。owner 可在平台直接选用，无需回传 Codex 才完成 prompt-only 交付。

## 页面与收尾

有 documents 技能时按其渲染；否则用已有 Word/WPS 或 LibreOffice 导出项目内 PDF，再转页图逐页看。只关闭本轮打开的文档，不改默认应用，不强装办公套件。失败可换已有后端，仍失败写“结构检查通过，页面未核实”。

检查标题、图比例、分页、截断、溢出、遗漏、同镜拆散与可复制性，保持视频唯一块完整，制作正文不夹管理报告。代码检查不能代替视觉检查；保存后再核对配对。

整理核对内容/哈希和去向，保留原稿/历史。确认产物路径、skill 缓存和测试输出；单项目检查不能证明其他磁盘无残留。收尾给完成内容、当前链接、实际检查边界、删除清单（如有）和下一步，不新增管理报告。
