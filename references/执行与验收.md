# 执行与验收

用于导出、文件整理及最终检查。自动检查适用于模板化当前稿；语义正确性仍须人工阅读，不为通过字段检查虚填内容。

## 必需字段与合理例外

| 对象 | 必需信息 | 例外 |
| --- | --- | --- |
| 剧本 | 目标时长、画幅、风格、故事/表达目标、分场动作、对白或无、预计时长 | 无角色/对白的展示片注明，无需虚构人物 |
| 人物 TXT | 参考图片、人物名称、主体描述、外形复用提示词、固定音色、试听台词、表演说明、声音状态 | 无发言人物写“无，本片不发言”；仅文字音色写未试听/绑定 |
| 分镜图 | 镜号、全片起止与成片时长、地点、主要环境锚点、连接素材、起始状态、图片 prompt、衔接 | 独立空镜/末帧复用/现成尾片注明类型与来源；分屏每侧一锚点后合成 |
| 视频与台词 | 同镜号与时间、画面输入、起始状态、视频 prompt、动作记录、台词、音效、衔接 | 复用镜注明来源与处理；无台词/音效明写无 |
| 每句台词 | 说话人、纯台词、完整固定音色、情绪、语速、镜内/全片发言时机 | 跨镜用一条完整音频，后镜注明复用来源和尾段时间 |
| 独立音效 | 名称、prompt、建议素材时长、出现动作/时机、必要衔接 | 无需求写无；连续底噪复用同一选用节点 |

两份提示词固定镜号对应，时间连续且时长相符。每轮台词声音与时机完整；视频中的可见角色台词与纯台词一致，画外声不能驱动画内其他人嘴巴。

缺图阶段标“待生成节点”，不放假文件链接；文字模式通过不能表述成资产已验收。历史只验证适用的静态配对和依赖，不用新模板强制改写历史。

## 路径与更新

```text
项目/
  剧本.docx
  分镜图提示词.docx
  视频提示词与台词.docx
  制作素材/人物、环境、道具/
  归档/
    文档源稿/同名.md
    历史版本/            # 仅既有冻结稿
    原始资料/原稿/      # 原名原内容
    临时工作/           # 已结束工作
  临时工作/             # 本轮有任务时使用
```

按需建目录。正式 Markdown 在“归档/文档源稿”，DOCX 在根目录。工作路径可以在“临时工作”或“归档/临时工作”下；非标准/嵌套源稿显式传 --项目目录，不从多层临时路径猜新根目录。路径解析后检查项目边界，不能只比字符串前缀。

导出器先检查候选 DOCX 的结构、链接与正文配对，再原子替换，失败保留旧文件。页面查看是独立步骤；发布前应先导草稿渲染，看图后再更新正式稿。

多份 Word/MD 不是文件系统事务：覆盖前在项目临时工作留必要回滚内容；中途失败恢复或明确待完成，不能称全部同步成功。导出器不自动合并用户修订，agent 必须先读正文、批注/修订并合并；--更新 不能代替这个动作。

## 调用

<技能目录>、<项目目录> 换成实际绝对路径；python 可用宿主已有解释器。

```text
python -B -X utf8 "<技能目录>/scripts/环境自检.py" --要求 text
python -B -X utf8 "<技能目录>/scripts/检查项目.py" "<项目目录>" --模式 text
python -B -X utf8 "<技能目录>/scripts/导出说明书.py" "<项目目录>/归档/文档源稿/分镜图提示词.md" --项目目录 "<项目目录>" --草稿
```

草稿默认到“临时工作/导出预览/同名.docx”。--输出 只能指定上述两类项目工作目录下的同名文件。预览后正式导出：

```text
python -B -X utf8 "<技能目录>/scripts/导出说明书.py" "<项目目录>/归档/文档源稿/分镜图提示词.md" --项目目录 "<项目目录>" --更新
python -B -X utf8 "<技能目录>/scripts/检查项目.py" "<项目目录>" --模式 word
```

首次无同名目标可省 --更新。自定义导出/库调用也跑最终检查。历史默认不写；明确修复才用 --修复归档，只在原历史位置处理，不复制成当前入口。

未知用途只允许草稿导出，不新增正式入口。默认无目录；owner 明确需要时才用 --目录，实际 Word/WPS 验证跳转。模板支持标题、段落、列表、链接、本地图片、text 块和分页，不把复杂表格/HTML 当已支持。

## 自动检查与人工责任

| 检查层 | 能证明 | 不能证明 |
| --- | --- | --- |
| 环境自检 | Python/库、部分本机渲染工具检测结果 | 云端生成权限、TapNow 功能、实际渲染成功 |
| 文字检查 | 命名/字段、可解析镜号与时间、部分引用、路径与静态依赖 | 台词自然、动作可行、画中物件数量、产品真实功能 |
| Word 配对 | 包可打开、正文/图片/链接与源稿配对 | 图片内容正确、无溢出、分页舒适、用户软件跳转正常 |
| agent 读稿对图 | 实际读到/看到内容的连续性与实物一致性 | 没看到的视频、未听的声音 |
| 页面渲染看图 | 已逐页查看的 DOCX 排版 | 用户另一办公软件一定相同 |
| owner 在 TapNow | 实际绑定、选用画面、口型/动作/音量与切镜 | 不能由本地文件存在代替 |

“通过”仅限脚本覆盖范围，未覆盖项单独注明。不可用模块记缺失/未验证，不能吞掉异常输出全部通过。

## 页面与收尾

有 documents 技能时按其渲染；否则用可用 LibreOffice 或 Word/WPS 导出项目内 PDF，再用 Poppler 等转页图，逐页查看。只关闭本轮打开的文档，不改默认应用、不为预览强装办公套件。失败可换已有后端，仍失败如实说明。

检查标题、图片比例、断页、页边溢出、遗漏、同镜信息拆散和文字可复制性。代码检查不替代视觉检查。保存后的 Word 再核对配对。

整理核对迁移前后内容/哈希与去向，原始来稿原样、历史冻结。核实本次实际产物所在路径和 skill 缓存；项目内检查通过不能证明磁盘其他位置无残留。收尾报告实际改动、测试、未核实项和删除清单，不另造管理材料。
