# 视觉方向与评审

在首次确定美术方向、设计关键分镜或修复具体视觉问题时取用。已有批准方向直接沿用；局部改稿只查受影响的选择，不重新做全片风格提案。方法分别适配 RampStack、art-direct 与电影单镜头设计，固定来源与许可见 [来源记录](../third_party/visual-direction/SOURCE.md)。这些是创作与评审方法，不是审美模型，也不保证成片效果。

## 一 先把方向变成可见选择

从剧本、品牌事实、owner 偏好与已有参考中提取以下四个维度，作为内部判断问题，不要求 owner 填表：

| 维度 | 需要决定什么 | 如何进入画面 |
| --- | --- | --- |
| 情绪语调 | 亲密、冷峻、轻快或庄重等，哪一种服务当前内容 | 人物距离、表演幅度、留白与节奏 |
| 审美取向 | 纪实、精密展示、手作质感或抽象表达等 | 构图秩序、材质、布景密度与用光 |
| 与观众的关系 | 陪伴观察、直接对话或引导体验等 | 视点、机位距离、是否直视镜头 |
| 感官重点 | 希望观众主要感受情绪、触感、空间或冲击等 | 清晰重点、明暗关系、运动幅度与已有声音设计 |

不把这些例子当风格菜单。组合有张力时说明如何实现，例如生活化人物可以与精细产品细节共存，但产品镜应继承同场光向并有动作接点。保留品牌与实物事实，不能为统一颜色重涂产品或改变结构。

把取舍收成少量可执行句，写入现有 `资产设定` 的“视觉基准”，未到资产阶段则使用剧本已有风格栏；每镜落实到原有 prompt，不复制四轴分析。可附一两个与本片有关的避用项，且说明原因。已有文字或参考足够时直接推进；缺项用标明的低风险假设，只有实质冲突且现有授权不能解决时才请 owner 决策。

例如亲情短片可写“以平视近距离观察为主；室内光有生活来源，保留自然肤色；产品近景继承环境光向；避免摆拍式笑容”。这是项目选择，不是所有片型的默认风格。不得把“电影感、高级、温暖”作为全部视觉指令，也不默认胶片颗粒、浅景深、固定焦段或暖橙色。

## 二 让镜头承担明确的事

先用一句话在内部回答“此镜让观众看见、理解或感受到什么”，再选视觉表达。下列五种视角是思考工具，不是五份必交方案，也不是光学镜头型号：

| 表达视角 | 适合承担的任务 | 使用边界 |
| --- | --- | --- |
| 直述 | 清楚展示已经具体的动作、物件或功能响应 | 不因追求新奇而遮掉关键事实 |
| 人物 | 通过反应、视线和距离表达关系 | 不用夸张表情代替处境依据 |
| 环境 | 让空间、空位或生活痕迹承载情绪与过渡 | 沿用现有锚点，不能凭空增添资产 |
| 隐喻 | 用已建立的可见关系承接抽象主题 | 观众能读懂，且不篡改剧情或产品事实 |
| 间接 | 用局部、遮挡或意外视点留下余味 | 不是天然更高级；不能牺牲必要信息和可生成性 |

遇到俗套先找具体处境中的动作或关系，不机械添加象征物。owner 已锁定的月亮、团圆、产品等元素不能因为常见就删除；检查它在本片中是否有具体动机，而非套用通用禁用清单。

只有关键镜头确实存在表达难题时，才试用电影单镜头方法：先想清叙事的拍法，再比较一个通过构图、空间或视线改善表达的拍法，并检查所选瞬间能否向下一秒延展。备选只作内部比较，默认交付一个最合适方案；不为每镜生成 A/B/C、额外图片或新的审批步骤。若差异只剩角度或形容词，就沿用已成立方案。

选定后落回本工作流原有提示词：明确主体和动作瞬间，选一个可信主要环境锚点，用景别、机位、遮挡、留白、光向说明观看重点。镜头术语相互一致，静态图只包含一个时刻，给下一动作保留空间；视频负责时间展开。分镜所画瞬间须与本镜“起始状态”一致；不能起始写尚未变化、图中却已经变化，视频又从头重做。首帧可用性还需实际生成验证，文字合理不等于画面通过。不把摄影师姓名、英文提示词、35mm 或特定平台参数设为必填项。

## 三 审查画面实际传达了什么

由现有独立视觉评审执行，不另设第四位剧本评审或新循环。先核对身份、产品事实、数量和连续性硬约束，再对照已批准方向与叙事任务。方向不同但同样成立时记为偏好，不把个人口味判成失败。

对实际看到的问题，按“意图 → 画面证据 → 差距 → 最小修复”形成现有问题记录：

- **意图**：此镜承担什么任务，依据哪条剧本、品牌事实或批准方向。
- **画面证据**：描述确实看到的构图、视线、光影、表演、材质或视觉重心；未看图时只能评提示词可能产生的效果，不写观察结论。
- **差距与影响**：是信息读不清、情绪偏离、产品抢戏，还是与邻镜不属于同一视觉空间；指明具体位置，不能只写“不够高级”。
- **最小修复**：指出保留的有效部分和需调整的局部；存在贯穿多镜的问题时归纳一条共同规则，仅核查受影响镜头。通过的资产与无关镜头保持冻结。

评审同时关注单镜观看重点与相关镜头之间的距离、光向、色彩和节奏关系。文本能检查切点设计；只有实际查看视频并听到声音后才能判断最终运动与音画衔接。不为凑问题强行改已经成立的画面。

例如剧本要求灯具响应后再赏月：有依据的问题是“画面只整体压暗，灯体与房间亮度关系没有变化，产品响应读不出来”；最小修复针对灯具可见亮度、必要环境受光及后镜低亮状态，不改全片色调。这是假设性说明，不代表已经看过本项目成片。

问题继续放入现有 `issues` 的位置、证据、影响和修复字段，每位至多三条实质问题；不增 schema、评分表或独立审美报告。主观分数不能覆盖硬约束，不设置自动及格分。prompt-only 仍只能交付“提示词通过，画面未验证”，无需平台回传。

## 四 保持集成轻量

本文件按需加载，运行不需要联网、外部完整 skill、API Key、模型权重或新 Python 包。默认不建情绪板、风格手册、逐镜评审 Word 或逐图 TXT；视觉基准与执行信息留在已有文档。现有图片足够就复用，不为审美方法而扩充素材库。

所有方案比较和修复沿用现有阶段、owner 授权、停止条件与生成额度；文本备选也不构成额外生图授权。不得引入上游的桌面导出、风格文件写入 skill 目录、供应商生成接口或完整调度器。小型电影镜头方法仅用于需要时的试用，以实际 owner 认可/否定样本校准，不宣称已被本片验证。
